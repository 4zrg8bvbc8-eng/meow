Install script

✓ Copied — now paste it into your userscript app

First time? Do this once

  1. Install a userscript app from the App Store — Userscripts (free) is recommended; Tampermonkey or Stay also work.
  2. Turn it on: Settings → Apps → Safari → Extensions, tap the app, set All Websites → Allow.

If you use Tampermonkey / Stay

  1. Tap Install script above.
  2. Your app shows an install screen — tap Install. Done.

If you use the Userscripts app

  1. Tap Copy script to clipboard above.
  2. In Safari, tap the ᴬA / puzzle button → Userscripts → ＋ New → paste → Save.

Then, on any page

  1. Tap the orange ✎ button (bottom-right).
  2. Tap Start editing, tap any text, retype it.
  3. Tap away (or press Return) to save, then Done.
  4. Reload — your edits are still there.

Everything stays on your device. It only changes what you see — the real website is unchanged for everyone else.
